🛡️ Espace organisateur

Crée et modifie les décorations, thèmes, tags et jeux — chaque catégorie a sa propre bulle ci-dessous. Pour attribuer une décoration/un thème/un tag à un joueur, utilise Paramètres > « Voir le profil d'un joueur ».

🖼️ Décorations de photo de profil

Le gabarit montre exactement où se trouve la photo de profil — importe-le dans ton logiciel d'image, dessine ta décoration autour du carré, puis importe le résultat ici. Une décoration créée ici démarre « non publiée » (visible seulement par toi) : utilise le bouton « Publier » dans la liste ci-dessus une fois prête.

🏞️ Fonds de profil

Le gabarit indique le format conseillé (plus haut que large) et un repère de zone visible — garde surtout l'essentiel de l'image bien centré, car la zone exactement visible varie un peu selon l'écran (accueil, popup « Voir le profil », recherche). Modifie le gabarit dans ton logiciel d'image puis importe le résultat ici. Un fond créé ici démarre « non publié » (visible seulement par toi) : utilise le bouton « Publier » dans la liste ci-dessus une fois prêt.

🎖️ Titres

Un titre créé ici démarre « non publié » (visible seulement par toi) : utilise le bouton « Publier » dans la liste ci-dessus une fois prêt, puis attribue-le à un joueur depuis Paramètres > « Voir le profil d'un joueur ».

🎨 Thèmes personnalisés

Le gabarit indique le format conseillé et la zone souvent recouverte par l'interface — modifie-le dans ton logiciel d'image puis importe le résultat ici.

🏷️ Tags de profil

Le gabarit indique la zone visible (cercle) — l'icône s'affiche toute petite et ronde, les coins de l'image seront invisibles. Un gif animé fonctionne aussi (gardé tel quel, ~300 Ko max) — une image fixe est recadrée et compressée automatiquement.
